# Wallet Service

REST‑сервис для управления балансом кошелька: пополнение, списание средств и получение текущего баланса.

## Стек

- Java 25
- Spring Boot (Web, Data JPA)
- PostgreSQL
- Liquibase для миграций БД
- JUnit 5, Mockito для модульных тестов
- Maven


## Запуск приложения

### Предварительные требования

- Java 25
- Maven
- Запущенный PostgreSQL (локально или в контейнере)

### Настройка базы данных

В `application.yml` (или `application.properties`) указать свои настройки подключения к PostgreSQL:

- URL
- имя пользователя
- пароль

Liquibase при старте создаст необходимые таблицы и данные.

### Команда запуска

```bash
mvn spring-boot:run
```


## Запуск через Docker

Приложение можно запустить в контейнерах (приложение + PostgreSQL) с помощью Docker Compose.

### Команда запуска

Из корня проекта:

```bash
docker-compose up --build

## REST API Эндпойнты

Базовый URL: `http://localhost:8080/api/v1/wallets`

| Метод | URL                    | Описание                            |
|-------|------------------------|-------------------------------------|
| POST  | `/operation`          | Пополнение или списание средств    |
| GET   | `/{walletId}/balance` | Получение текущего баланса кошелька |
 
```
Проверено на Docker Desktop (Windows, backend WSL2, образ eclipse-temurin:25-jdk-alpine)

## Тестирование

Для сервисного слоя написаны модульные тесты на JUnit 5 и Mockito:

- успешное пополнение кошелька;
- успешное списание средств;
- ошибка при попытке списать больше доступного баланса;
- успешное получение баланса по идентификатору;
- ошибка при запросе баланса несуществующего кошелька.

Запуск тестов:

```bash
mvn test
```
